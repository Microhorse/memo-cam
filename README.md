# 📸 メモカメラ (MemoCamera)

4:3の写真・動画の下部に白い余白をつくり、撮影日時・メモ・GPS位置情報を1つのファイル（JPEG / MP4）として残す、広告ゼロ・外部通信ゼロのシンプルな記録用Androidカメラアプリです。

## ✨ 主な特徴
1. **写真も動画も「4:3 ＋ 下部白余白メモ合成」に対応**：
   - 写真だけでなく、動画（MP4）の下部にも白い余白・撮影日時・メモを合成してカメラロールへ保存します。
2. **撮影場所のGPS位置情報（EXIF / MP4メタデータ）同時保存**：
   - 撮影したJPEG画像およびMP4動画にGPS座標と撮影日時を記録し、標準ギャラリーやGoogleフォトの地図表示と連動します。
3. **快適なカメラ操作**：
   - 「写真 / 動画」ワンタップ切替、本体音量ボタン（＋／ー）でのシャッター・録画操作、ワンタップ倍率切替（0.5x / 1x / 2x）＆ピンチズーム、常時点灯ライト（トーチ）、セルフタイマー（3秒 / 10秒）、シャッター触覚フィードバックを搭載。

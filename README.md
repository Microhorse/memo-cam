# 📸 メモカメラ (MemoCamera)

思い出記録・日常・旅行・グルメ用の**インスタ・ストーリー（9:16）対応 ポラロイド風メモ付きカメラ Androidアプリ**です。
「撮影(3:4) → ゼロタップで思い出メモ入力 → 下部白余白へ日時・タグ・メモを合成して全体9:16で保存 → 即座に次の撮影へ復帰」を単一画面（Single Screen）で完結させます。

## ✨ 主な特徴（「材集カメラ」からのカスタマイズ点）
1. **Instagram ストーリーぴったりの「9:16」ポラロイド風合成**：
   - カメラで撮影した `3:4` 写真の真下に白余白（`9:4` 相当）を自動追加し、**合成後の画像全体が `9:16`（ストーリーの縦横比ぴったり）**になるよう仕上げます。
   - インスタのストーリーにそのままアップしても上下左右が見切れず、メモ文字も綺麗に収まります（長文入力時は文字サイズを自動縮小して `9:16` 枠内に収めます）。
2. **🔦 ライト常時点灯（トーチ）モード搭載**：
   - フラッシュ（撮影瞬間だけ光るモード）ではなく、シャッター横の **`[ 🔦 ライトOFF / 💡 ライトON ]`** ボタンでスマホのLEDライトを常時点灯できます。暗い店内での料理撮影や夜の記録でも、明るさを目で確認しながら撮影できます。
3. **シンプルで使いやすい思い出記録仕様**：
   - 業務用の仮決めチェックボタンを省き、タグ（`#日常`、`#旅行`、`#グルメ` など自由追加）とメモ入力に特化。
   - パッケージID（`com.solso.memocamera`）とアイコン色（アンバーオレンジ）を分けているため、同じスマホに「材集カメラ」と「メモカメラ」の両方を並べてインストールできます。
4. **起動0秒＆ゼロタップ文字入力＆待ち時間ゼロの連続撮影**：
   - シャッターを切った瞬間にメモ欄へ自動フォーカス＆キーボード起動。「保存して次へ」で即座にカメラへ復帰し、裏側で `DCIM/MemoCamera/<タグ名>` と `DCIM/Camera`（カメラロール）へ高品質JPEG（95%）を保存します。

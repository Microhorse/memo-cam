# 📸 メモカメラ (MemoCamera)

4:3の写真の下部に白い余白をつくり、撮影日時・メモ・GPS位置情報（EXIF）を1枚の画像として残す、広告ゼロ・外部通信ゼロのシンプルな記録用Androidカメラアプリです。

## ✨ 主な特徴
1. **4:3 フル画角 ＋ 下部白余白メモ合成**：
   - 写真本体に文字を被せず、下部の白い余白に撮影日時とメモを端正に印字します。
2. **撮影場所のGPS位置情報（EXIF）同時保存**：
   - 撮影したJPEG画像にGPS座標と撮影日時を記録し、標準ギャラリーやGoogleフォトの地図表示と連動します。
3. **快適なカメラ操作**：
   - 本体音量ボタン（＋／ー）でのシャッター撮影、ワンタップ倍率切替（0.5x / 1x / 2x）＆ピンチズーム、常時点灯ライト（トーチ）、セルフタイマー（3秒 / 10秒）、シャッター触覚フィードバックを搭載。
